Trigger an update by calling:

  • Cricket: PUT /api/stats/cricket/update with body: { "matchId", "playerId", "teamName", "runs" }
  • Football: PUT /api/stats/football/update with body: { "matchId", "playerId", "teamName" }

Use Postman (or similar) and send the request with a valid admin Authorization: Bearer <token> header.
